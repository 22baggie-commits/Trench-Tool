## 📋 Overview

Trench Tool is a comprehensive desktop application designed for cryptocurrency portfolio automation and analysis on Solana. The application provides real-time market tracking, integrated DEX connectivity, and automated asset discovery — all in a clean, user-friendly interface.

---

## ✨ Key Features

- Automated portfolio tracking and analysis on Solana
- Real-time market data processing
- Integrated DEX connectivity
- Multi-asset price monitoring
- Automated balance calculation
- Custom alert and notification system
- Local encrypted storage (AES-256)
- No mandatory account creation
- Interactive portfolio charts
